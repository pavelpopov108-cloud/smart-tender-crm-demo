# Смарт Тендер CRM — кликабельный макет

Макет CRM для отдела холодных звонков: 10 экранов, страница «Почему так» и тур на 2 минуты.
Статичный сайт без сервера и сборки: HTML, CSS и немного JS.

**Все данные выдуманные.** ИНН начинаются с кода региона 00 (такого региона нет), телефоны в диапазоне +7 (900) 000-…, совпадения с реальными компаниями случайны. Звонки, письма и уведомления в макете никуда не уходят. Действия сохраняются только в браузере; сбросить их можно в меню пользователя справа сверху.

Экраны: Планёрка 10:00, Мой день, Пирожки, Обзвон, Карточка компании, Клиенты, Подборки, Входящие, Импорт базы, Шпаргалка.
